# ARYA

Pre-launch site for [arya.clothing](https://arya.clothing): premium activewear for him and her, designed in California.

Plain HTML, CSS and JavaScript. There is no build step.

- `index.html`: page content, meta and link-preview tags
- `styles.css`: design tokens, layout and motion
- `script.js`: hero video, collection colonnade, signup forms (Klaviyo) and UTM capture
- `assets/`: images, video, logos
- `share.jpg`: link-preview image

Pushing to `main` deploys to arya.clothing through Vercel (project `arya-site`).

The previous Next.js site is preserved on the `legacy-nextjs-site` branch.
